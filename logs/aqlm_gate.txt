=== AQLM week-1 quality gate ===
Question: do learned-codebook 2-bit experts (AQLM-class, arXiv 2401.06118) hold quality
near the 4-bit baseline where affine 2-bit collapses? If yes -> expert bytes halve ->
~2x decode headroom -> Metal kernel worth writing. If no -> kill the track.

Source caveat (pre-registered): the FP4/FP8 original checkpoint is deleted; the only
weight source is the repacked mixed-4/8 (4-bit affine experts, group 64). Quantizing
from dequantized-4-bit stacks error-on-error, so every ppl here is an UPPER BOUND on
what codebook-2bit from the true source would do. A pass from degraded source is a
stronger pass.

Method: 6 contiguous mid layers (18-23), all 256 experts x 3 projections each,
dequantized to fp32 and re-quantized three ways, served back through the normal
streaming store in the 4-bit affine container (justification: arm A measures exactly
the container roundtrip error; if arm A ~= baseline, the container is transparent and
arms B/C isolate the quantizer). Other 37 layers untouched.

Arms:
  A control:      dequant fp32 -> mx.quantize(bits=4, g64) -> container  (plumbing only)
  B codebook-2bit: dequant fp32 -> additive VQ: vectors of 8 consecutive weights,
                   2 codebooks x 256 entries (16 bits / 8 weights = 2.0 bits/weight),
                   k-means init + alternating refinement, per-output-channel LS scale
                   -> reconstruct fp32 -> mx.quantize(bits=4, g64) -> container
  C affine-2bit:  dequant fp32 -> mx.quantize(bits=2, g64) -> dequant -> mx.quantize(bits=4) -> container
Weight-only objective (no activation calibration) — full AQLM adds activation-aware
calibration on top, i.e. further upside beyond whatever B shows here.

Eval: ppl_streaming.py, wikitext-2 windows 1-8 (8184 scored tokens), 8 GB cache.
Baseline all-normal-layers = 3.9492 (logs/ppl_streaming.txt, commit b9374ec).

PRE-REGISTERED GATE CRITERIA (decided before any run):
  PASS: arm B within ~1-2% of arm A, AND arm C markedly worse
        (C must be clearly worse or the test is underpowered -> extend to 12 layers
        before concluding anything).
  KILL: arm B degrades >5% over arm A on the subset.

=== GATE VERDICT: KILL ===
  Pre-registered PASS required arm B within ~1-2% of arm A; pre-registered KILL was
  >5% degradation. Measured: +9.44% -> KILL. The test was powered (arm C +10.97%
  clearly detected at 6 layers; no 12-layer extension needed). Codebook 2-bit
  recovered only ~14% of the affine-2bit ppl damage (4.3211 vs 4.3814 against A's
  3.9483) despite 25% lower weight MSE (0.113 vs 0.150) — the weight-MSE advantage
  does not translate into perplexity on this model.
  Naive compounding extrapolation to all 43 layers: x1.91 -> full-corpus ppl ~11.7
  (vs 6.125 published) for arm B; ~12.9 for arm C. Both unacceptable.
  Upper-bound caveat (pre-registered): source weights were already 4-bit affine
  (original FP4/FP8 checkpoint deleted), so these numbers are an upper bound on ppl;
  a KILL from degraded source is weaker than a KILL from true source would be, BUT
  the miss is ~5-9x the pass band, far beyond what error-stacking plausibly explains
  (arm A shows the stacking path itself costs ~nothing).
  Untested upside noted for the record: full AQLM adds activation-aware calibration
  + per-layer finetuning; weight-only was the pre-registered week-1 objective.
  Metal-kernel phase: MOOT (gate killed the track).
